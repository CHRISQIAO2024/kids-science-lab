# 🌟 少儿科学互动实验室 (Kids Science Lab)

专为中小学生设计的 **46 个趣味物理、数学几何、三角函数、3D 宇宙与前沿复杂系统** 互动科普实验。

在线免安装、零门槛，全端适配手机、平板（iPad/Android）与电脑浏览器，即开即玩！

## 📚 实验展馆目录（共 6 大分类 46 个实验）

### 1. 🎯 经典物理动态仿真（8 个）
*基于 SVG 与 Canvas 动态仿真，动手调节重力、角度与质量，揭示经典物理规律：*
- **子弹与小球同时落地** —— 平抛运动与自由落体竖直运动独立性探究
- **行星轨道等面积定律** —— 开普勒第二定律（近日点加速飞奔、远日点从容慢行）
- **单摆机械能守恒** —— 动能与重力势能实时互转柱状图对比
- **救护车的声音变化** —— 多普勒效应波前压缩与音调由高变低
- **光纤传光的秘密** —— 拨动滑块探索光的全反射与临界角
- **双水波相遇干涉** —— 波峰与波峰相遇激起双倍巨浪、波峰与波谷相遇水面静止
- **磁铁穿过线圈生电** —— 拖拽磁铁体验法拉第电磁感应生电
- **粒子在磁场中画圆圈** —— 观察带电粒子在垂直磁场中的洛伦兹力偏转与回旋加速

### 2. 🚲 数学几何与机械轨迹（6 个）
*探寻自然界与现代工业中最神奇的几何曲线：*
- **自行车轮与神奇拱门** —— 旋轮线（摆线）：下滑速度天下第一的最速降线
- **四角尖尖的星形** —— 星形线 Astroid 几何探秘
- **蚊香与黑胶唱片** —— 经典等距阿基米德螺线
- **不会卡住的齿轮轮廓** —— 圆的渐开线 Involute：让现代机械运转自如的秘密
- **示波器上的神秘舞蹈** —— 正交简谐振动合成的李萨如图形 Lissajous
- **悬索桥与挂绳的曲线** —— 纯重力作用下自然雕琢出的悬链线 Catenary

### 3. 🎡 三角函数动态可视化（6 个）
*把枯燥的公式变成摩天轮上的高低起伏与投影节拍：*
- **摩天轮与波浪线** —— 正弦函数 $\sin$ 动态投影与周期波动
- **横向影子的左右节拍** —— 余弦函数 $\cos$ 动态投影
- **冲向无穷高的天梯** —— 正切函数 $\tan$ 割线与渐近线探秘
- **余切函数演化** —— 余切 $\cot$ 几何投影
- **正割函数演化** —— 正割 $\sec$ 倒数与极值
- **余割函数演化** —— 余割 $\csc$ 倒数与对称

### 4. 🌍 天体自然与工程系统原型（7 个）
*结合实际生活与前沿工程的综合科学交互原型：*
- **太阳·地球·月亮与24节气** —— 3D 呈现地轴倾斜23.5度下的公转自转与四季冷暖
- **比亚迪云巴基地轨道交通** —— 智能立体交通调度与多车运行
- **野生动物保护智能巡航** —— 无人机高空巡检与野生动物 AI 识别
- **智能 AI 助眠机器人** —— 拟人呼吸节律灯效与睡眠情绪感知
- **全天候智能安全自行车** —— 环境光敏自适应车灯与防追尾激光雷达
- **智能单词记忆翻转卡** —— 艾宾浩斯遗忘曲线交互记忆卡片
- **疯狂接金币物理小游戏** —— 重力加速度与刚体碰撞检测小游戏

### 5. 🚀 3D 宇宙天文与空间探索（Three.js，10 个）
*拖拽三维视角，漫游宏大太空与古代文明：*
- **中华十大古天文遗址 3D 探索馆** —— 登封观星台、陶寺古观象台与古代实证历法
- **太阳系航行时间模拟器** —— 光速飞船在太阳系行星间的真实飞行尺度
- **远地轨道卫星群仿真** —— 数百颗通信与导航卫星交织的太空天网
- **深空黑洞引力漩涡** —— 广义相对论引力透镜、吸积盘与反转排斥
- **星际跃迁 3D 全息视界** —— 常规巡航、光速跃迁与时空折叠科幻视界
- **粤港澳大湾区夜航 3D** —— 低空无人机俯瞰湾区城市灯光群
- **森林救援无人机 3D** —— 三维密林雷达搜寻与小动物救援任务
- **机器人校园巡逻 3D** —— 自主路径规划与安全打卡哨点
- **梦幻海底世界 3D** —— 阳光穿透水层的深海群鱼游弋与日夜光影
- **侏罗纪 3D 巡游** —— 穿越远古恐龙大陆与喷发火山岛

### 6. 🌌 量子态与群体智能视觉实验（Canvas/JS，9 个）
*启发孩子理解“状态、参数与自组织涌现”：*
- **群智涌现 Agent 鸟群** —— Boids 算法：个体极简规则涌现出群体雁阵风暴
- **量子交互流场** —— 向量场扰动与数万发光粒子动力学
- **量子星轨引力场** —— 多重引力源下的对称粒子星轨
- **神经涌现向量流场** —— 模拟大脑神经思维通路的心流演化
- **赛博神经突触网络** —— 点击神经元激活连锁动作电位闪电传导
- **高维折叠拓扑织网** —— 高维超立方体空间投影的折叠与牵引
- **液态金属拓扑融合** —— 表面张力、深渊聚变与高能裂变
- **混沌边缘奇异吸引子** —— 洛伦兹吸引子与著名的“蝴蝶效应”
- **语义粒子重构** —— 发光粒子随指令重组凝聚为思维词汇

## 🛠️ 技术特点

- **Pure Web Standards**：纯原生 HTML5 / CSS3 / JavaScript / SVG / Canvas / WebGL (Three.js)。
- **Zero Build, Zero Dependency Install**：无需 `npm install`、无需构建工具、无需后端服务器，开箱即用。
- **全端自适应**：手机纵向/横向、平板触摸屏、台式电脑键盘与鼠标全适配。
- **教学启发性**：每一个实验都配有核心问题与启发式说明，让孩子从“观察现象”走向“理解本质”。
